# Contributing to Agentic Finance Network

Thank you for your interest in contributing to Agentic Finance Network.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Install the project dependencies.

    pip install -r requirements.txt

## Running the Project

Start the multi-agent network with:

    python main.py

This launches the Coordinator, Market, Risk, and Execution Agents through the Fetch.ai uAgents Bureau.

## Development Guidelines

- Keep changes focused and well documented.
- Follow the existing project structure.
- Maintain compatibility with Fetch.ai uAgents.
- Keep the project simulation-only unless explicitly stated otherwise.
- Update documentation whenever functionality changes.

## Reporting Issues

If you discover a bug or have an enhancement suggestion, please open a GitHub Issue including:

- Expected behaviour
- Actual behaviour
- Steps to reproduce
- Relevant logs or screenshots

## Pull Requests

Before submitting a Pull Request:

- Verify the project runs successfully.
- Keep commits clear and descriptive.
- Update documentation where appropriate.

Thank you for helping improve Agentic Finance Network.
