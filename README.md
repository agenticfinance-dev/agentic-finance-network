# Agentic Finance Network

An autonomous multi-agent financial intelligence network built with Fetch.ai uAgents.

## Overview

Agentic Finance Network demonstrates how specialised AI agents collaborate to analyse market data, assess risk, and coordinate execution decisions.

## Agents

- Coordinator Agent
- Market Agent
- Risk Agent
- Execution Agent

## Technology

- Python 3
- Fetch.ai uAgents
